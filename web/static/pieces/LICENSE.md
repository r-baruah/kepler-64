# Chess piece images

The twelve SVG files in this folder (`wK.svg` ... `bP.svg`) are the "cburnett" chess set by Colin M. L. Burnett, copied unmodified from Wikimedia Commons (checked 2026-10-25). Each file name maps to the Commons file below (w = light, b = dark).
